# EV-Charging-Demand-Prediction-and-Usage-Pattern-Analysis

Objective

Developed a machine learning system to analyze EV charging station usage patterns and predict charging demand based on factors such as charger type, location, charging company, time of charging, and historical usage behavior. 

Project Objectives

- Analyze EV charging usage patterns.
- Predict numerical charging demand using Regression models.
- Classify charging sessions into High Demand and Normal Demand.
- Compare Machine Learning model performance.
- Explain model predictions using Feature Importance, SHAP, and LIME.

Technologies Used

- Python
- Jupyter Notebook (Anaconda)
- Pandas and NumPy
- Scikit-learn
- XGBoost and LightGBM
- SHAP and LIME
- Streamlit
- Plotly
  
Project Features

1. EV Charging Overview
2. Usage Pattern Analysis
3. Regression Prediction
4. Classification Prediction
5. Model Performance Comparison
6. Model Explainability

Output

An interactive Machine Learning dashboard that helps analyze EV charging behavior, predict charging demand, identify high-demand sessions, compare model performance, and understand important prediction factors.
